# Muan Meurer — Engineering Portfolio

Personal engineering portfolio built with Jekyll and hosted on GitHub Pages.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Open `http://localhost:4000`.

## Main content

- `_config.yml` — identity, links, skills, and global metadata
- `_includes/hero.html` — homepage hero and calls to action
- `_includes/about.html` — short professional introduction
- `_projects/` — individual project case studies
- `css/styles.css` — site styling and responsive behavior
- `assets/` — images, videos, resume, and scripts

## Deployment

Push changes to the `main` branch. GitHub Pages rebuilds the site automatically.
